# Виртуальное СЕО (Virtual CEO)

## Что это
Мультиагентная система с главным оркестратором (Virtual CEO), который управляет специализированными агентами для автоматизации бизнес-процессов медиа-холдинга. Цель — увеличить выручку, сократить операционные косты, дать основателю инструмент контроля без погружения в рутину.

## Владелец
**Ibakdaulet** — казахстанский медиа-предприниматель, основатель Kettik Group.

## Следующая задача: партнёрская система в Grants Bot

**Концепция обсуждена, не реализована.**

**Идея:** Grants KZ будет направлять лидов к партнёрам-консультантам по поступлению и зарабатывать комиссию 10% с каждой продажи.

**Согласованный флоу:**
```
Пользователь консультируется → бот предлагает партнёра (кнопки)
→ пользователь выбирает → вводит имя + телефон
→ запись в "Лиды" (статус: Новая)
→ Telegram-уведомление продавцу партнёра
→ через N дней бот автоматически пишет продавцу: "Что с заявкой [имя]?"
→ продавец отвечает кнопкой: В работе / Продажа / Отказ
→ если Продажа → бот спрашивает сумму → считает 10% → записывает в таблицу
```

**Партнёры:**
- Сейчас: один партнёр (компания, помогает по разным странам, но не всем)
- Потом: несколько партнёров по направлениям/странам — пользователь будет выбирать из списка
- Пока один партнёр → показываем как одну кнопку, потом расширим

**Открытые вопросы (нужно уточнить у Ibakdaulet перед реализацией):**
1. Telegram ID или username продавца партнёра (для уведомлений)
2. Через сколько дней делать follow-up (предложено 3 дня)
3. Таблица та же (`1VJh2uN3tw14wXBVxduDXVE7lIgJWK3MMXg34IZd3JTY`) или отдельная?
4. Партнёр предпочитает Telegram-уведомления или просто смотрит таблицу?
